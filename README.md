# Catholic Money Course: Featured Podcast Episodes

Page for Holy Family (Auburn) and St. Andrew (Sumner) parishioners: https://pskip0.github.io/catholicmoney/

Each bulletin graphic QR code opens `#ep-YYYY-MM-DD` (the Sunday date). Episodes are listed in the `EPISODES` array in `index.html` and appear at 12:00 AM Pacific on the Saturday of their bulletin weekend.

Preview every episode, including ones not yet visible: https://pskip0.github.io/catholicmoney/?preview

## Monthly update rule
Every episode should have all four links: Apple Podcasts, Spotify, YouTube and Overcast (direct episode links, never show pages). When adding episodes, if any link can't be found, add the episode with the links that exist and notify Paul (push notification) listing each episode and the missing platform(s). The ?preview page also shows a "Missing links" box.
